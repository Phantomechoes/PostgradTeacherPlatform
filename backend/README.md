# backend

这里是**后端**：运行在服务器上的程序，负责接收请求、执行业务规则、读写数据库。

可以把它理解成仓库里的“柜台后厨”。管理后台和小程序都是窗口；真正算规则、存数据的工作以后都在这里完成。

当前阶段（S0-01）只建立空目录，**没有可运行程序**。

- 真正的 FastAPI 工程从 **S0-02** 开始
- 数据库连接和迁移从 **S0-03** 开始
- 本目录现在不得放入 `pyproject.toml`、业务 Python 文件或依赖安装结果

约定的分层（请求从上到下）：

```text
API / Router  →  Service  →  Repository  →  Model  →  PostgreSQL
```
